# Freedoom HD monsters

Monster sprites from [Freedoom](https://github.com/freedoom/freedoom), upscaled 4x with
Real-ESRGAN by the [freedoom-hd](https://github.com/m4cd4r4/freedoom-hd) project (release v1.0).

License: Freedoom's art is BSD 3-Clause. The notice in `COPYING.adoc` must stay with these
files and with any binary distribution of the game; `CREDITS` lists the Freedoom contributors.
The freedoom-hd upscaling pipeline is MIT licensed.

Changes made here: the upscaled files have a solid magenta background, which was made
transparent, and the pink fringe it left around each sprite was trimmed. Only the frames the
game uses are included.

File names follow Doom: four-letter monster name, frame letter, then `1` for the view from the
front or `0` for a frame that looks the same from every side.
