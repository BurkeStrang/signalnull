# Poly Haven textures and sky

Photographed materials and a sky panorama from [Poly Haven](https://polyhaven.com). License:
CC0 1.0 (public domain); no attribution is required. The materials are unmodified 1K downloads.

Each material has a colour map (`_diff_`) and an ambient-occlusion map (`_ao_`). The game
multiplies the two when it loads them.

| Material | Used for |
| --- | --- |
| [`metal_plate_02`](https://polyhaven.com/a/metal_plate_02) | outer walls |
| [`rusty_metal_grid`](https://polyhaven.com/a/rusty_metal_grid) | pillars |
| [`blue_metal_plate`](https://polyhaven.com/a/blue_metal_plate) | pillars |
| [`metal_plate`](https://polyhaven.com/a/metal_plate) | floor |

`shanghai_bund_sky.jpg` is cut from the 8K tonemapped JPEG of the
[Shanghai Bund](https://polyhaven.com/a/shanghai_bund) panorama: the full 8192-pixel width, and
only the 548 rows from the horizon up to about 24 degrees, which is all the game can see.
